# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not**
open a public GitHub issue. Instead, report it privately using one of the
following channels:

- GitHub's [private vulnerability reporting](../../security/advisories/new)
  feature for this repository, or
- Email Hyland's security team at **security@hyland.com** with a detailed
  description of the issue, steps to reproduce, and any relevant logs or
  proof-of-concept code.

We will acknowledge receipt of your report, investigate, and follow up with
remediation timelines. Please allow reasonable time for a fix to be released
before any public disclosure.

## Supported Versions

Security fixes are provided for the latest released version of the MCP server.
Older versions are not guaranteed to receive patches.
