# Nuxeo MCP Server Instructions for AI Agents

This document provides instructions for AI agents to install, run, and use the Nuxeo MCP Server.

## 1. INSTALLATION

### Prerequisites
- Python 3.11 or higher and uv (https://docs.astral.sh/uv/)
- git
- A Nuxeo server instance

### Installation Steps
```bash
git clone https://github.com/nuxeo/nuxeo-mcp-server.git
cd nuxeo-mcp-server
uv sync --frozen
```

### Nuxeo Server for Testing (Optional)
```bash
# Nuxeo with embedded OpenSearch, needed by the Query DSL and audit tools
docker run -d --name nuxeo -p 8080:8080 \
  docker-private.packages.nuxeo.com/nuxeo/nuxeo-mcp-demo:2025
curl http://localhost:8080/nuxeo/runningstatus
```

## 2. RUNNING THE SERVER

Credentials are required: there is no default identity.

```bash
# stdio, the default: an MCP client starts the server
NUXEO_URL="http://localhost:8080/nuxeo" NUXEO_USERNAME="Administrator" \
  NUXEO_PASSWORD="Administrator" uv run nuxeo-mcp

# Streamable HTTP, served at http://localhost:8181/mcp
NUXEO_URL="http://localhost:8080/nuxeo" NUXEO_USERNAME="Administrator" \
  NUXEO_PASSWORD="Administrator" uv run nuxeo-mcp --http --port 8181
```

The server stops at startup if the credentials are missing or rejected.

## 3. AVAILABLE TOOLS AND RESOURCES

### Tools

Documents are referenced by `ref` (a path or a UID) on read tools, by `path` or
`uid` on update, and by `uid` only on delete and move.

Read:

1. `nuxeo_get_repository_info` - `{}`
2. `nuxeo_list_children` - `{"ref": "/default-domain/workspaces"}`
3. `nuxeo_get_document` - `{"ref": "/default-domain/workspaces/My Document"}`
   - Options: `fetch_blob: true` for the main blob, `rendition: "thumbnail"`, `conversion_format: "pdf"`, `as_resource: true`
   - Returns the document as markdown text.
4. `nuxeo_search_documents` - `{"query": "<NXQL>", "page_size": 10, "page_index": 0}`
   - Read `nuxeo://nxql-guide` first and start from its default filter: `ecm:mixinType != 'HiddenInNavigation' AND ecm:isProxy = 0 AND ecm:isVersion = 0 AND ecm:isTrashed = 0`
   - Returns: `documents[]` (id, documentType, title, path, createdAt, modifiedAt, createdBy, modifiedBy, metadata, score, snippets, extensions) plus totalCount, pageIndex, pageSize, hasMore, mode, interpretedQuery, degraded
   - For counts or groupings use `nuxeo_search_documents_with_query_dsl`.
   - `"mode": "semantic"` matches a question on meaning, only on servers with vector search; elsewhere it fails with an error saying so: then search by exact terms with NXQL `ecm:fulltext` and do not retry semantic. Optional `nxql_filter` and `include_snippets`.
5. `nuxeo_search_documents_with_query_dsl` - `{"query": {<OpenSearch request body>}}`
   - Read `nuxeo://query-dsl-guide` first. Returns the engine response plus `_nuxeo_executed_query` and, on empty results, `_nuxeo_hint`.
6. `nuxeo_search_audit_with_query_dsl` - `{"query": {<OpenSearch request body>}}`
   - Administrators only. Read `nuxeo://audit-query-dsl-guide` first.
7. `nuxeo_list_document_types` - `{}`
8. `nuxeo_get_metadata_schema` - `{}`
9. `nuxeo_list_operations` - `{}`

Write:

10. `nuxeo_create_document` - `{"parent_path": "/default-domain/workspaces", "name": "my-document", "type": "File", "properties": {"dc:title": "My Document"}}`
    - Optional `file_path` to attach a file from the MCP server's machine: refused over HTTP unless `NUXEO_MCP_UPLOAD_DIR` is set, then confined to it. Returns `uid` and `path`; confirm with `nuxeo_get_document`, search may not see it yet.
11. `nuxeo_update_metadata` - `{"path": "/default-domain/workspaces/my-document", "properties": {"dc:title": "Updated Title"}}` (or `uid` instead of `path`)
12. `nuxeo_move_document` - `{"document_uid": "<uid>", "target_path": "/default-domain/workspaces/archive"}`, optional `new_name`
13. `nuxeo_delete_document` - `{"uid": "<uid>"}`
14. `nuxeo_execute_operation` - `{"operation_id": "Document.Lock", "input_type": "document_uid", "input_value": "<uid>"}`

### Resources

1. `nuxeo://info` - basic information about the connected Nuxeo server
2. `nuxeo://{uid}` - a document by UID, e.g. `nuxeo://12345678-1234-1234-1234-123456789012`
3. `nuxeo://{path}` - a document by path, e.g. `nuxeo://default-domain/workspaces/my-document`
4. `nuxeo://nxql-guide` - NXQL for `nuxeo_search_documents`
5. `nuxeo://query-dsl-guide` - field reference for `nuxeo_search_documents_with_query_dsl`
6. `nuxeo://audit-query-dsl-guide` - field reference for `nuxeo_search_audit_with_query_dsl`

### Discovering Tools and Resources
Use the MCP Inspector to discover available tools and resources:
```bash
npx @modelcontextprotocol/inspector --config mcp.json --server default
```

## 4. CONFIGURATION

### Environment Variables
- `NUXEO_URL`: URL of the Nuxeo server (default: `http://localhost:8080/nuxeo`)
- `NUXEO_USERNAME`: Username for Nuxeo authentication (required for Basic auth, no default)
- `NUXEO_PASSWORD`: Password for Nuxeo authentication (required for Basic auth, no default)
- `NUXEO_MCP_AUTH_MODE`: `local` (default, only value): every caller acts as the one configured Nuxeo identity
- `NUXEO_MCP_UPLOAD_DIR`: only folder `file_path` may read from; unset: any file over stdio, none over HTTP
- `NUXEO_MCP_READ_ONLY`: `true` hides the write tools (create, update, move, delete, execute operation); default `false`

### Client Configuration
See nuxeo_mcp_config.md for stdio and HTTP examples.

## 5. TROUBLESHOOTING

### Common Issues

1. Connection Issues
   - Ensure Nuxeo server is running
   - Verify URL, username, and password
   - Check network connectivity

2. Authentication Issues
   - Verify credentials
   - Check user permissions

3. Document Not Found
   - Verify document path or ID
   - Check if document exists in Nuxeo

### Using MCP Inspector
```bash
npx @modelcontextprotocol/inspector --config mcp.json --server default
# Web interface at http://localhost:6274
```

## 6. EXAMPLE WORKFLOW

`use_tool(server, tool, arguments)` is pseudo-code for your MCP client's tool call.

```python
# Get repository info
repo_info = use_tool("nuxeo", "nuxeo_get_repository_info", {})
print(f"Connected to repository: {repo_info['repositoryName']}")

# Search for live files
search_results = use_tool("nuxeo", "nuxeo_search_documents", {
    "query": "SELECT * FROM File WHERE ecm:mixinType != 'HiddenInNavigation' AND ecm:isProxy = 0 AND ecm:isVersion = 0 AND ecm:isTrashed = 0",
    "page_size": 5
})
print(f"Found {search_results['totalCount']} documents")

# Create a new document
new_doc = use_tool("nuxeo", "nuxeo_create_document", {
    "parent_path": "/default-domain/workspaces",
    "name": "my-new-document",
    "type": "File",
    "properties": {
        "dc:title": "My New Document",
        "dc:description": "Created by MCP"
    }
})
uid = new_doc["uid"]
print(f"Created document with ID: {uid}")

# Read it back by UID (returns markdown)
print(use_tool("nuxeo", "nuxeo_get_document", {"ref": uid}))

# Update document
use_tool("nuxeo", "nuxeo_update_metadata", {
    "uid": uid,
    "properties": {
        "dc:description": "Updated by MCP"
    }
})

# Delete document
use_tool("nuxeo", "nuxeo_delete_document", {"uid": uid})
```
